# 练字 · Claude Code 技能包

把少儿硬笔书法教学经验外化成 AI 技能——**分诊台式智能路由 + 五大子技能**。

## 这是什么

一套 Claude Code 自定义 Slash Command，让 AI 变成你的「亲子练字智能助教」。核心设计：

```
家长提问 → /练字（分诊台）→ 追问 → 确认 → 路由到子技能
                                    ↑
                          子技能答不了 → 兜回来
```

**不是关键词匹配。** 主入口会追问到足够清楚再分配，子技能答不了自动兜回主入口重新分析。

## 安装

```bash
# 1. 克隆仓库
git clone https://github.com/WangYouxin/calligraphy-skills.git

# 2. 复制技能到 Claude Code 用户目录
cp -r calligraphy-skills/skills/* ~/.claude/skills/

# 3. 重启 Claude Code，输入 /练字 开始
```

或者只安装单个技能：

```bash
cp -r calligraphy-skills/skills/练字 ~/.claude/skills/
```

## 使用示例

### 示例 1：模糊问题 → 追问 → 诊断

```
用户：/练字 孩子字写得不好

AI：多大了？你说的不好——具体是哪种？字歪？大小不一？往上飘？还是写得慢老擦？

用户：8岁，写字慢，老用橡皮擦。

AI：他握笔的时候手指会不会捏得很紧？写一会儿会不会喊手酸？

用户：会喊酸，握笔像握拳头。

AI：我梳理一下——8岁孩子，写字慢+擦+握笔紧+手酸。这个需要系统性排查，从手到字逐层找根因。
    转到诊断——[调用 /练字-诊断]
```

### 示例 2：归因态度 → 引导 → 转习惯

```
用户：/练字 他就是懒，不认真写

AI：先别急着给他贴标签。你观察过没有——他写字的时候手酸不酸？趴着写是不是因为看不到？

用户：没注意过……好像是趴着写。

AI：好，那我们先不说是「懒」。很多孩子趴着写是因为握笔太低，坐直了看不到字。
    转到习惯引导——从身体和标准的角度重新看看。
```

### 示例 3：简单问题 → 直接回答

```
用户：/练字 描红有用吗？

AI：描红基本没用——孩子只是跟着线走，脑子没参与。
    你家孩子是不是描红练了挺久但写作业就乱？
    [路由到 /练字-问答 详细解答]
```

## 核心公理

这六个技能都基于以下五条核心公理：

1. **练字的本质是「找到问题→纠正过来」** — 练了没进步，不是孩子不是这块料，是链条的某个环节断了
2. **手对了，字自然对** — 根因 80% 在手（握笔、发力、手腕、坐姿），只调字不调手 = 治标不治本
3. **时长是放大器** — 放大的是你现在在练的东西。练对了越长越好，练错了越长越糟
4. **行为问题先查身体** — 70% 身体 + 20% 标准 + 10% 态度
5. **结论让他自己说** — 用提问引导家长自己发现根因，比你告诉他有效十倍

## 知识基础

这套技能基于真实的少儿硬笔书法教学经验——一个看过几百个孩子的书法老师才知道的东西。知识体系包括：

- **29 条诊断知识**（方法论 7 + 诊断 22）
- **L1-L8 层级诊断链**（手型→握笔→坐姿→手腕→笔画→速度→习惯→综合）
- **11 条横向必查规则**（铁三角、包笔三件套、手酸定位等）
- **互动引导话术**（提问→观察→自己发现→结论自己说）
